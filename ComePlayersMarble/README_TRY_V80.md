# ComePlayers Marble V80

V80 is a full-project visual remake release built from V79.

## Open correctly
1. Extract the ZIP into a new folder.
2. Do not overwrite V79.
3. Delete `library`, `temp`, `build`, and `.creator` if Cocos generates them.
4. Open the folder in Cocos Creator 3.8.8.
5. Confirm the lobby header says `CLASSIC CLIENT V80` and `V80 FULL CLASSIC VISUAL REMAKE`.

## Visible V80 checks
- Central rotating ComePlayers globe and city towers.
- Deeper property cards with group pips and miniature city silhouettes.
- Larger corner tiles and stronger ownership flags.
- Distinct villa, building, hotel, and landmark silhouettes.
- Match mode and threat rails above the board.
- Persistent classic client navigation at the bottom of the lobby.

V79 save data remains compatible.
