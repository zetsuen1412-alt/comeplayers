# V88 Fortune Signal Director

V88 changes local Fortune tiles from a passive reveal into a readable three-card decision.
The deck offers three unique cards from the seeded draw pile. Human players select one card;
bots score the visible options based on immediate economy, defense, property growth, attacks,
movement, Island state, and World Travel utility.

The HUD displays card rarity, category, and a concise effect forecast. Persistent card resources
are visible throughout the match in a dedicated Fortune rail. The authoritative online match
adapter remains server-controlled; the interactive local choice system does not overwrite server snapshots.
