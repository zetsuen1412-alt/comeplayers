# V52 Loadout and Active Skills

ComePlayers Marble V52 adds a local pre-match loadout layer inspired by classic PC marble games while keeping all code, names, art, and rules original to ComePlayers.

## Loadout rules

- One owned pendant can be equipped.
- One owned booster can be selected.
- Pendants are permanent inventory items and are never consumed.
- The selected booster is consumed only when a local match actually starts.
- Restarting or starting another match consumes another selected booster when stock remains.
- All purchases use local CP earned inside the prototype. No real-money checkout exists.

## Pendant catalog

- Banker Badge: +CP 200,000 starting capital.
- Travel Compass: +1 free World Travel ticket.
- Architect Blueprint: +1 free property upgrade credit.
- Insurance Charm: 35% reduction on the first rent payment.

## Booster catalog

- Marble Fund: +CP 150,000 starting capital.
- Upgrade Permit: +1 free property upgrade credit.
- First Class Ticket: +1 free World Travel ticket.
- Rent Shield: 50% reduction on one rent payment.

## Active character skills

Each equipped character has one skill that can be activated once per match during the human player's idle decision phase.

- Alexia — Route Override: gain one World Travel ticket.
- Nova — Turbo Capital: receive CP 250,000.
- Lux — Instant Permit: gain one free upgrade credit.
- Onyx — Rent Barrier: reduce the next rent payment by 60%.
- Mira — Safe Passage: clear Island turns and gain one travel ticket.
- Volt — Overcharge: receive CP 120,000 and one upgrade credit.

Skills cannot be used during a modal decision, bot turn, tutorial, pause menu, or after the match ends.

## Save migration

The local save bundle is now version 3. Version 2 and version 1 save bundles are migrated automatically. Existing cards, career progress, settings, and currency are preserved. A default starter loadout is added only when an older character progression has no item inventory field.
