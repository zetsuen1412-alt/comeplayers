# V76 Fullscreen Classic Visual Overhaul

V76 addresses the visual mismatch visible in the supplied localhost screenshots. The previous canvas was letterboxed inside a nearly square preview area, making the game appear tiny with large grey bands. Both preview and web templates now use the full available landscape container.

The lobby is shifted away from a modern web-dashboard appearance through a permanent sky/tabletop fallback, brighter classic blue surfaces, gold bevels, a room-event ribbon, and stronger nested frames. The match view uses a complete-board camera, compact roll controls, avatar-oriented corner player cards, pastel city groups, ivory tile foundations, warm wood, restrained gold trim, and original center props.

This release preserves all V75 gameplay systems and does not copy Modoo Marble logos, characters, or proprietary art.
