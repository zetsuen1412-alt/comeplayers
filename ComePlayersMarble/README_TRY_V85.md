# ComePlayers Marble V85 - Classic Broadcast & City Economy

1. Extract this full project into a new empty folder.
2. Open it with Cocos Creator 3.8.8.
3. Remove `library`, `temp`, `build`, and `.creator` if they came from another workspace.
4. Open `assets/scenes/Match.scene`.
5. Run Preview. The lobby must show `V85 CLASSIC BROADCAST & CITY ECONOMY`.

V85 adds broadcast towers, active-turn satellites, route step gates, destination fins, property rent meters, economy orbiters, live City Intel, and tighter camera framing.
