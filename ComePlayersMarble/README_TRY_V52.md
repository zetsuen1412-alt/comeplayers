# Try ComePlayers Marble V52

1. Open this project with Cocos Creator 3.8.8.
2. Wait until asset import is complete.
3. Open `assets/scenes/Match.scene`.
4. Press Preview.
5. Open Shop to purchase a pendant or booster using local CP.
6. Open Inventory to equip a pendant and select a booster.
7. Create a local room and start the match.
8. During your turn, press the purple character-skill button before rolling.

The selected booster is consumed when the match starts. Pendants remain owned permanently.

This environment did not contain Cocos Creator, so preview and platform builds must be run on a computer with Cocos Creator 3.8.8 installed.
