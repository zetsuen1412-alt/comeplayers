# ComePlayers Marble V89

1. Extract the full project into a new empty folder.
2. Open the folder with Cocos Creator 3.8.8.
3. Do not copy `library`, `temp`, `build`, `node_modules`, or `.creator` from an older project.
4. Run the Match scene.
5. Confirm the lobby shows `V89 SPECIAL DISTRICT STRATEGY`.
6. Test Game Center risk lanes, World Travel forecasts, Olympic forecasts, and the new special-tile monuments.
7. Run `npm run verify` from the project folder for static release verification.

A Web Desktop build is not included unless Cocos Creator has actually produced one on the current machine.
