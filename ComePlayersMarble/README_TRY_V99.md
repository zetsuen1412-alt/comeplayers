# ComePlayers Marble V99 — Replay Coach & Decision Review

1. Extract this full project into a new empty folder.
2. Open it with Cocos Creator 3.8.8.
3. Do not copy `library`, `temp`, `build`, `.creator`, or `node_modules` from an older project.
4. Play and finish a local match to save a replay.
5. Open Replay Studio to view the Replay Coach grade, score, strengths, next focus, and key moments.
6. Existing V98 local replays are analyzed automatically when loaded.

The lobby should display `V99 REPLAY COACH & DECISION REVIEW`.
