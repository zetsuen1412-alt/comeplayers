# ComePlayers Marble V81

V81 is a full-project classic world parity release built from V80.

## Open correctly
1. Extract the ZIP into a new empty folder.
2. Do not overwrite V80 or an older Cocos project folder.
3. Before opening, remove any copied `library`, `temp`, `build`, `.creator`, or `node_modules` folders.
4. Open the project using Cocos Creator 3.8.8.
5. Wait until Cocos finishes importing all assets.
6. Confirm the lobby header shows `CLASSIC CLIENT V81` and `V81 CLASSIC WORLD PARITY`.

## Visible V81 checks
- Bright blue arcade-style board frame instead of the dark V80 tabletop.
- Ivory property cards with saturated district bands and gold trim.
- Large central sky-world diorama with clouds, globe, skyline ring, card decks, and dice arena.
- Larger villa, building, hotel, and landmark silhouettes.
- Owner flags face the correct direction on all four sides.
- More top-down camera with the whole board still visible.
- Blue/gold HUD chrome with smaller player cards and dice controls.

## If an old version still appears
1. Close Cocos Creator and every browser preview tab.
2. Delete `library`, `temp`, `build`, and `.creator` from the extracted V81 folder.
3. Reopen the V81 folder in Cocos Creator 3.8.8.
4. Use Project > Build and select the V81 project scene.
5. Hard-refresh the browser preview with Ctrl+F5.

V80 saves remain compatible.
