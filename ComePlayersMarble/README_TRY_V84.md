# ComePlayers Marble V84 - Living Board Director

1. Extract the full project to a new empty folder.
2. Open the folder using Cocos Creator 3.8.8.
3. Delete `library`, `temp`, `build`, and `.creator` if copied from an older local workspace.
4. Open `assets/scenes/Match.scene`.
5. Run Preview. The lobby must display `V84 LIVING BOARD DIRECTOR`.

V84 adds active-player spotlights, living property districts, a central match director hub, a turn-order rail, landing crown bursts, and two-stage landing camera direction.
