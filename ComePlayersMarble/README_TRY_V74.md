# ComePlayers Marble V74

Open this clean project with Cocos Creator 3.8.8 and run the main scene.

V74 is the first gameplay presentation convergence pass based on the unified Modoo Marble reference package. Check the following during play:

1. The complete board remains visible in the tighter isometric overview.
2. The center of the board is clear and reserved for the two premium dice.
3. The ROLL action is circular and centered in the lower dock.
4. Player panels show live rank, total asset, cash, city count, and building count.
5. Dice results use one large center number before pawn movement.
6. Pawn movement uses short controlled hops instead of exaggerated bouncing.
7. Property popups show the action cost and remaining balance.
8. Every event returns the camera to the board overview.

Read `docs/MODOO_MASTER_REFERENCE_V74.md` before continuing the visual parity roadmap.

Run `npm run verify` before creating a release build.
