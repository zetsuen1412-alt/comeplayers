# ComePlayers Marble V76

## Important: rebuild before comparing
The browser screenshot from V75 can remain visible when Cocos Creator is still serving an old preview cache.

1. Close the old localhost preview tab.
2. Open this V76 project folder in Cocos Creator 3.8.8.
3. Delete the generated `library`, `temp`, and `build` folders if they were created by an older project copy.
4. Reopen the project and use **Project > Run Preview**.
5. Confirm the lobby header says `V76 CLASSIC VISUAL OVERHAUL`.

The preview and web templates are now forced to landscape fullscreen, so the game should no longer appear as a small 16:9 strip inside a nearly square grey canvas.
