# ComePlayers Marble V100 — Adaptive Replay Academy

1. Extract this full project into a new empty folder.
2. Open it with Cocos Creator 3.8.8.
3. Do not copy `library`, `temp`, `build`, `.creator`, or `node_modules` from an older project.
4. Finish at least one local match so Replay Coach can generate an Academy profile.
5. Open Replay Studio to view the Academy tier, training focus, trend, consistency, recommended replay, and three adaptive drills.
6. Existing V99 replay records migrate automatically to Replay Library version 3.
7. Existing local saves migrate automatically from version 11 to version 12 without resetting Career, Journey, Rival, or Replay data.

The lobby should display `V100 ADAPTIVE REPLAY ACADEMY`.
