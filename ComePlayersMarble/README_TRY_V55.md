# ComePlayers Marble V55 — Ranked Season

## Requirements

- Cocos Creator 3.8.8
- Windows 10/11 recommended for Editor Preview

## Preview

1. Add the `ComePlayersMarble` folder to Cocos Dashboard.
2. Open it with Cocos Creator 3.8.8.
3. Wait for asset import to finish.
4. Open `assets/scenes/Match.scene`.
5. Press Preview.
6. From the lobby, press **RANKED MATCH** or open **RANKED** from the bottom navigation.

## Ranked flow

- The first five matches are placement matches.
- Ranked uses four players and fixed 20-second turns.
- Matchmaking AI changes with rating and placement status.
- Solo placement or Team victory changes RP.
- Complete five ranked matches in the current local week to unlock a CP reward.
- Open the Ranked page and press **CLAIM REWARD**.
- Season and weekly progress are stored on the current device.

## Local-only notice

V55 Ranked Arena is an offline/local progression prototype. It does not connect to a public competitive server, and the leaderboard rivals are simulated profiles. Online anti-cheat, server-authoritative rating, accounts, and cross-device synchronization remain future work.

## Save migration

V54 local-save version 3 automatically migrates to V55 local-save version 4. Existing character collection, inventory, career, missions, settings, and match history remain intact. Ranked progress starts at 1000 RP.
