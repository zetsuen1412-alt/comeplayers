# ComePlayers Marble V72

## Premium 3D Dice

Open the project with Cocos Creator 3.8.8 and run the main scene. Start a match and press **ROLL**.

The dice are now generated from layered 3D geometry:

- glossy inset face panels
- metallic outer shell
- gold edge rails
- rounded corner caps
- recessed gold pip rings
- raised ivory pip caps
- improved PBR reflections and shadows

The update only changes presentation. Authoritative roll results, multiplayer synchronization, replay data, and old saves remain compatible.

Run `npm run verify` before packaging a release.
