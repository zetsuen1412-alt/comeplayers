# ComePlayers Marble V82

V82 is a full-project world match cinematic update built from V81.

## Open correctly
1. Extract into a new empty folder.
2. Do not overwrite V81 or an older project folder.
3. Remove `library`, `temp`, `build`, `.creator`, and `node_modules` if copied from another folder.
4. Open using Cocos Creator 3.8.8 and wait for asset import to finish.
5. Confirm the lobby shows `WORLD CLIENT V82` and `V82 WORLD MATCH CINEMATIC`.

## Visible V82 checks
- Four spectator terraces with animated colored crowd lights.
- Orbit racers moving around the central world globe.
- Property tiles have inset faces and district crest badges.
- Movement path includes glowing arrows and a destination ring.
- Active tile has a layered focus beam.
- Landing produces shockwave rings and vertical rays.
- Character movement is flatter and less bouncy.
- Board occupies more of the screen.
- Arrival popup uses blue/gold client chrome.

V81 save data remains compatible.
