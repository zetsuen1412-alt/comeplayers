# ComePlayers Marble V77 - How to Test

1. Extract the ZIP into a new empty folder.
2. Do not overwrite an old V67-V76 project folder.
3. Delete `library`, `temp`, `build`, and `.creator` if they exist beside the extracted project.
4. Open the extracted folder using Cocos Creator 3.8.8.
5. Wait for assets and scripts to import completely.
6. Preview the project in landscape mode.
7. Confirm the lobby status says `V77 CLASSIC PARITY OVERHAUL`.
8. Start a local match and confirm:
   - The board uses ivory rectangular property tiles and warm wood framing.
   - Four compact player cards sit near the screen corners.
   - The ROLL button is purple and centered at the bottom.
   - The full board remains visible in the overview camera.

The clean source archive intentionally excludes generated folders and a prebuilt web build.
