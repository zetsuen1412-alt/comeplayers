# v0.14.5 — Export Spreadsheet per Menu

- Export tidak lagi bergantung pada satu menu Export Semua Data.
- Pesanan: filter periode, sumber, dan kode order; export hanya hasil filter.
- Mutasi: export mengikuti periode, sumber, dan pencarian kode order yang aktif.
- Stok/Gudang: export mengikuti filter Game dan Jenis (Gold/Item).
- Gaji: export mengikuti filter Semua/FH1/FH2/FH3/ADMIN.
- Karyawan: export mengikuti filter FH dan status.
- Tutup Buku: export mengikuti tanggal + jam periode Closing yang dipilih.
- Menu Export Spreadsheet global dihapus dari sidebar agar alur lebih sederhana; halaman lama tetap ada untuk kompatibilitas.
- Panduan diperbarui agar menjelaskan export per menu.
