# CHANGELOG v0.14.1

## ADMIN sebagai bagian ke-4

- Pilihan bagian karyawan sekarang: **FH1, FH2, FH3, ADMIN**.
- ADMIN tersedia saat menambahkan karyawan.
- Filter Gaji sekarang memiliki tombol **ADMIN**.
- Export Excel Closing menambahkan sheet **GAJI ADMIN**.
- Seed Supabase menambahkan team code **ADMIN**.
- Assignment, stok, mutasi, kasbon, dan payroll dapat membawa nilai bagian `ADMIN` seperti FH lainnya.
