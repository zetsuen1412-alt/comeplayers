# v0.14.4 — Export Spreadsheet

- Menambahkan menu **Export Spreadsheet**.
- Satu tombol menghasilkan satu file `.xlsx` berisi: RINGKASAN, MUTASI, STOK, PENJUALAN, PAYROLL GAJI, TUTUP BUKU, dan KARYAWAN.
- Export adalah aksi baca saja dan tetap dapat digunakan ketika sistem sedang dikunci untuk Closing.
- Nama file otomatis menggunakan waktu export.
- Export Mutasi dan Excel Closing yang sudah ada tetap dipertahankan.
