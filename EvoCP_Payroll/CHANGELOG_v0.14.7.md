# v0.14.7 — Export Spreadsheet Lebih Rapih

- Seluruh export Excel sekarang memakai gaya visual yang mengikuti referensi workbook EVO GAMING 2026:
  - judul hitam dengan branding EVO COMEPLAYERS,
  - bar informasi/filter berwarna biru,
  - header kolom berwarna menurut jenis data,
  - border tabel rapih,
  - lebar kolom disesuaikan,
  - format Rupiah untuk kolom uang,
  - format persentase untuk pembagian gaji,
  - warna status selesai/bermasalah/proses,
  - kode order/karyawan dibuat menonjol,
  - AutoFilter pada header,
  - baris ringkasan/total dibuat lebih jelas.
- Berlaku untuk Export Mutasi, Penjualan/Pesanan, Stok/Gudang, Payroll Gaji, Karyawan, Closing, dan Export Semua Data.
- Filter/periode yang sedang dipilih ditampilkan di bagian atas file Excel hasil export.
- Closing Excel tetap memisahkan Ringkasan, Ringkasan Sumber, Mutasi, Pendapatan, Gaji FH1/FH2/FH3/ADMIN, Ditunda, Stok Gudang, dan Masalah.
