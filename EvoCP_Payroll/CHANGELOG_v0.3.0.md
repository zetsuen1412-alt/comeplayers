# Perubahan v0.3.0

1. Tutup buku setiap 14 hari.
2. Tanggal awal siklus tutup buku dapat diatur.
3. Semua order menampilkan hari, tanggal, bulan, tahun, dan jam.
4. Menu Mutasi ditambahkan kembali.
5. Mutasi dapat dilihat Semua, Hari ini, atau rentang tanggal bebas.
6. Pembagian harga order dapat diatur per order.
7. Sistem menampilkan bagian karyawan dan bagian perusahaan.
