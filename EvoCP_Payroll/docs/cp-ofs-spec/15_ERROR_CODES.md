- `UNAUTHORIZED`
- `FORBIDDEN`
- `ORGANIZATION_MISMATCH`
- `LAST_OWNER_CANNOT_BE_REMOVED`

## AI

- `AI_OUTPUT_INVALID`
- `AI_CONTEXT_FORBIDDEN`
- `AI_SCAN_UNAVAILABLE`

## Guidance

API responses include a human-safe message, optional structured details, and `retryable`. Never expose SQL internals or secret data in user-facing error details.
