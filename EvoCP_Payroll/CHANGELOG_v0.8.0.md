# CP-OFS Simple ID v0.8.0

## Asisten AI / Pemeriksa Lokal
- Menu baru **Asisten AI**.
- Pemeriksaan **Mutasi**, **Gaji**, dan **Tutup Buku**.
- Menjelaskan masalah menggunakan Bahasa Indonesia sederhana.
- Menampilkan nilai uang yang terkait masalah jika ada.
- Tombol langsung membuka order terkait.
- Tanya AI mode demo untuk pertanyaan: omzet, uang masuk, order belum selesai, gaji, karyawan terbesar, masalah, dan kesiapan tutup buku.
- Asisten bersifat baca/saran: tidak dapat mengubah nominal, membayar gaji, atau menutup buku sendiri.

## Keamanan konsep
Versi demo ini menjalankan pemeriksaan secara lokal dari data CP-OFS sehingga dapat dicoba tanpa API key dan tanpa biaya AI. Integrasi model AI eksternal dapat ditambahkan kemudian di server dengan data yang telah disanitasi dan izin read-only.
