# Perubahan v0.4.0

## Tutup buku dapat diatur
- Mode periode otomatis.
- Tanggal awal siklus dapat dipilih.
- Lama periode dapat diisi sendiri: misalnya 7, 14, 15, 30 hari.
- Mode tanggal bebas: pilih tanggal awal dan akhir sendiri.
- Pengaturan tutup buku disimpan di browser pada mode demo.

## Export Spreadsheet / Excel
- Menu Mutasi memiliki tombol **Download Excel**.
- File Excel mengikuti filter: semua, hari ini, atau rentang tanggal.
- Menu Tutup Buku memiliki **Download Excel periode ini**.
- Laporan tutup buku berisi sheet:
  - Ringkasan
  - Pesanan & Mutasi
  - Gaji
  - Masalah

## Catatan
Pada mode demo data masih merupakan data contoh. Setelah database ComePlayers asli dihubungkan, tombol Excel akan mengambil data asli dari periode/filter yang dipilih.
