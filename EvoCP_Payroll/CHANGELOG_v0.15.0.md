# v0.15.0 — Stok Terjual

- Menambahkan kolom **Stok terjual** di menu Stok / Gudang.
- Stok terjual bertambah otomatis ketika order Gold/Item ditandai selesai dan stok benar-benar dikonsumsi.
- Stok yang baru dicadangkan belum dihitung sebagai terjual.
- Export Stok dan snapshot Stok pada Closing sekarang menyertakan kolom **STOK TERJUAL**.
- Data stok lama di browser dimigrasikan otomatis dengan nilai stok terjual awal 0.
