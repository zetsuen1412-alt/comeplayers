# ComePlayers ChatGPT upload package

Upload all three ZIP files below to the same ChatGPT Project. Each archive uses the same top-level `Comeplayers-new/` directory, so together they represent the current project source and the large CP Empires & Allies asset library.

1. `Comeplayers-new-ChatGPT-Part-1-Source-2026-07-16.zip` — application source, configuration examples, tests, documentation, and current Strike V04/Monopoly V22 code — 80.96 MB
2. `Comeplayers-new-ChatGPT-Part-2-GameAssets-A-2026-07-16.zip` — first CP Empires & Allies game asset group — 261.49 MB
3. `Comeplayers-new-ChatGPT-Part-3-GameAssets-B-Mods-2026-07-16.zip` — remaining CP Empires & Allies assets, mods, and template artwork — 274.51 MB

SHA-256 checksums are stored in `SHA256SUMS.txt`.

Real environment files, credentials, private keys, local databases, dependency folders, generated build output, caches, installers, Git metadata, logs, old ZIP exports, and backup copies are intentionally excluded.
