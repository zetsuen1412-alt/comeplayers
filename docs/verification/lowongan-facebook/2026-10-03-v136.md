# Facebook Lowongan v1.3.6 — existing group-feed support

Branch: `codex/facebook-lowongan-stabilize-v2`, PR #46. Base: `cd3d50e477892ee58d50bdb7829dc3e27eaa71c2`.

## Behavior

The extension scans ordinary DIV posts when a story marker and one unambiguous
post-header permalink establish the post boundary. It rejects comment/reply
permalinks and links mentioned only in the post body.

For an admin-selected image-comment job, the worker first performs a read-only
probe of an already loaded feed in the same group. It reuses that feed only if
the exact target has a uniquely matched post context and one top-level composer.
Otherwise it navigates to the canonical target as before. A pending navigation,
another group, a nested reply, an active overlay, or ambiguous target blocks reuse.

The content script rechecks the exact target throughout attachment and after
server preflight, immediately before the send click. STOP during probing blocks
navigation and dispatch. STOP during upload can remove the job's proven owned
photo in the same feed. A changed target or ambiguous draft pauses for review
without sending or discarding a potentially user-owned draft.

No server, website, database, permission, dependency-lockfile, or unrelated module
changes are included. The reviewed KIRIM KOMENTAR click and no-blind-retry behavior
are retained. The manifest is now 1.3.6; reload the extension and Admin page before
testing, and confirm that Admin displays 1.3.6.
