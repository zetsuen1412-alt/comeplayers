# Checkpoint model dari referensi

Sepuluh model baru dan teksturnya disimpan di `production/reconstruction/roster-reference-2026-10-04/viewer/models`. Galeri offline dibangun dari GLB sebenarnya. Workspace Blender gabungan memuat seluruh model dan gambar tertanam; sumber Pip dengan scene lama yang dipertahankan ada dalam arsip terpisah.

Pip telah direvisi delapan kali menjadi koper robot dengan pendamping, 13 joint mekanis dan enam clip. Mochi mempertahankan ujung ekor asli dengan sambungan baru pada sisi tersembunyi. Sembilan model bertekstur lain tampil statis. Materi kulit/pakaian mendapat koreksi parameter pencahayaan; tekstur asli dan geometri delapan model lain tetap utuh.

Kesamaan desain belum final. Tekstur belakang, jari, aksesori kecil, retopologi, rig dan deformasi masih perlu diperbaiki. Model belum diintegrasikan ke runtime game. Detail sumber, hash, batas interpretasi serta pemeriksaan independen tersedia pada folder `evidence` dan manifest.

Gunakan `PORTABLE_GUIDE_ID.txt` untuk melanjutkan di komputer lain. Snapshot ini memperluas seluruh scope checkpoint gameplay yang ada dan mempertahankan inventori lama beserta model asalnya.
