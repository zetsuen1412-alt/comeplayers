# Rebuild the selected HIGH Alexia

Use Python 3.12 with NumPy 2.3.5. Run this command from the extracted review
root, using fresh output and receipt paths outside the review:

```text
python -B evidence/selected-alexia/recipes/rebuild_high_visual_review.py --review . --chain evidence/selected-alexia/rebuild-chain.json --baseline evidence/selected-alexia/source/alexia-baseline.glb --out-dir ../CRWT-HIGH-rebuilt --receipt ../CRWT-HIGH-rebuild-proof.json --expected-candidate-sha256 e88b27e4a71058a4576fb4ab1b3d6d24a621d771175ce700a9a3e959729daf52 --expected-step-count 9 --source-gate
```

The wrapper checks all delivered recipe, input and proof hashes. It executes
the nine recipes in order, checks every intermediate model, then requires the
final GLB to match `viewer/models/alexia.glb` byte for byte. Original review
files and their modification times stay unchanged. The final GLB is written
to `../CRWT-HIGH-rebuilt/clean-anatomy/alexia.glb`.

The nine steps author the hair, headphone band, hair material and garment;
remove retained garment fragments; author rear calves; perform two further
bounded cleanups; and replace the visible hand/leg skin. All required inputs
are local: the e18 baseline GLB, unchanged six-view reference, semantic hair
mask, two hair-boundary masks, original garment mask, and the two protector
masks generated by earlier cleanup stages. The delivered chain selects their
exact canonical paths and hashes. No Blender, renderer, browser, repository,
network service or image generation is needed for this model rebuild.

Original source streams remain stored, while triangle routing and closed new
surfaces replace the corrupted visible regions. The final visible hands and
legs are authored replacements; original warm-skin triangle visibility is
not preserved. The face/eyes/front identity, precision cups, existing nineteen
joints, bind matrices and `IdleBreath`/`Walk` clips remain protected.

The native Blender review and actual renders are restored as reviewed bytes;
this command does not recreate them. The clips remain manual prototypes, with
separate overlapping hand forms and no production finger articulation, foot
IK, collision or game integration certification.

The delivered standalone wrapper uses its corrected Windows/POSIX path check.
It validates the complete actual nine-step contract before creating outputs.
