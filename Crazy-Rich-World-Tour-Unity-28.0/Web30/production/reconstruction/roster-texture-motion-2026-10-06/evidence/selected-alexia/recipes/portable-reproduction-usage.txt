Alexia texture cleanup followed by manual skeletal motion

Requirements: Python 3, NumPy and Pillow for the texture recipe. The motion
builder uses Python 3 and NumPy. Both standalone recipes use explicit inputs
and contain no historical workspace imports. Original reference pixels are
read only. Blender is optional for inspecting/editing the actual native rig.

From the delivered review root, use the packaged recipes and original baseline:

python evidence/selected-alexia/recipes/build_semantic_palette_soft_volume.py --source evidence/selected-alexia/source/alexia-baseline.glb --reference references/alexia-blue-v2-turnaround.png --output-parent ../CRWT-Alexia-texture-motion-rebuilt --variant soft-volume-protected

python evidence/selected-alexia/recipes/build_alexia_motion_exact_closure_v2.py --source ../CRWT-Alexia-texture-motion-rebuilt/soft-volume-protected/alexia.glb --semantic-mask ../CRWT-Alexia-texture-motion-rebuilt/soft-volume-protected/semantic-masks.npz --output-parent ../CRWT-Alexia-texture-motion-rebuilt --name alexia-texture-motion

Both output children must be new. The output parent is outside the delivered
review root, so review/inventory inputs remain unchanged. The texture step
appends only a replacement mesh0 COLOR stream. The motion step preserves every
active static texture input stream and appends JOINTS/WEIGHTS, skeleton, skins,
inverse-bind matrices and real joint animation channels.

IdleBreath: 3.6 seconds. Walk: 1.2 seconds. Each has 49 authored key times.
Walk is an in-place alternating leg/knee/foot and arm step. The root stays
fixed. This manual merged-chibi prototype lacks production foot IK, contact,
collision, root travel, facial rigging and dynamic hair. Its small joint angles
limit but do not certify against coat/hair/body intersections. The suitcase is
a rigid right-hand accessory; head, cups and rear hair locks move together.

Native/color representation follows the Blender importer. Source GLB streams
remain exact at rest except the selected texture COLOR replacement. Numerical
proofs do not replace actual rendered motion review or production approval.
