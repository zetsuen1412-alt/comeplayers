# CRWT26 Weather & VFX Production

Weather 26.0 hanya presentation layer. Tidak ada RNG gameplay, ekonomi, posisi, turn, bankruptcy, atau winner yang ditentukan oleh cuaca.

## Effects
- Rain / storm / lightning
- Snow / sugar snow
- Fog
- Sakura / sparkle / fireflies / breeze
- Night city lights
- Water reflection shimmer + rain ripples
- Landmark night glow
- Festival fireworks
- Low-power/reduced-motion density controls
