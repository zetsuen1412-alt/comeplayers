# CRWT25 Living World Environment

Environment 25.0 adalah presentation layer saja. Sistem ini tidak menentukan RNG, ekonomi, posisi, turn, atau pemenang.

## Sistem
- Dynamic day/night lighting
- Traffic / train / carriage
- NPC walkers
- Vegetation sway
- Water shimmer + boats
- Map-specific weather particles
- Airplane / balloons / ambient props
- Low-power density reduction
- Reduced Motion support
