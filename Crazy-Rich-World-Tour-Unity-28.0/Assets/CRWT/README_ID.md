# CRWT Unity Runtime 30.0 — Chibi World

Folder inti client Unity 6 Crazy Rich: World Tour. Scene dibuat otomatis oleh `CrwtProjectSetup` saat project pertama kali dikompilasi.

`CrwtDicePresenter` mengatur animasi; `CrwtStarDieGraphic` menggambar Starwheel tujuh outcome; `CrwtDiceRules` memvalidasi payload dan cursor roll. Hasil gameplay hanya dari Supabase. `CrwtMatchController` menahan penerapan posisi sampai reveal selesai.
