# Buka Crazy Rich 29.0 di Unity 6

1. Buka **Unity Hub**.
2. Pastikan **Unity 6** terpasang.
3. Untuk Android, pasang modul **Android Build Support + SDK/NDK + OpenJDK** dari Unity Hub.
4. Klik **Add project from disk** dan pilih folder `Crazy-Rich-World-Tour-Unity-28.0`.
5. Tunggu compile + Package Manager selesai.
6. Scene akan dibuat otomatis. Jika belum, klik menu **Crazy Rich > 29.0 > Setup Project**.
7. Buka `Assets/CRWT/Scenes/CRWT_Bootstrap.unity`.
8. Tekan **Play**.

Build cepat:
- **Crazy Rich > 29.0 > Build Windows**
- **Crazy Rich > 29.0 > Build Android APK**

Nama folder asal 28.0 tetap dipertahankan. Unity Editor tidak tersedia pada mesin pengembangan ini, sehingga visual Play Mode serta APK/EXE 29.0 belum diverifikasi. Ikuti [QA 29.0](QA_29_ID.md) untuk pengujian perangkat.
