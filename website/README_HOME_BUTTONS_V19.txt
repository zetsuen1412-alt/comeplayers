Perubahan:

- Tombol utama memakai ikon, label kecil, accent line, dan arrow circle.
- Tombol pendukung dibuat sebagai tech-chip biru/emas.

- Tidak ada animasi karakter atau animasi background.
- Hanya hover/click effect ringan pada tombol.
- Route /messages dan /marketplace tidak diubah.

Cara pasang:
1. Hentikan server dengan Ctrl+C.
2. Extract seluruh isi ZIP ke C:\Comeplayers-new\website
3. Pilih Replace/Timpa semua file.
4. Jalankan INSTALL_HOME_BUTTONS_V19.bat
5. Jalankan npm run dev dan buka http://localhost:3000
6. Tekan Ctrl+F5.
