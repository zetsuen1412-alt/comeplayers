DESAIN:

- Download PC dan Download Android dibuat kecil/minimal
- Alexia besar di kanan
- Header dan footer lama disembunyikan hanya pada route homepage (/)

CARA PASANG:
1. Stop server dengan Ctrl+C.
2. Extract semua isi ZIP langsung ke folder website yang memiliki package.json.
3. Pilih Replace/Timpa semua file.
4. Jalankan INSTALL_STACKED_FOCUS_V11.bat.
5. Jalankan npm run dev.
6. Buka http://localhost:3000 lalu tekan Ctrl+F5.
