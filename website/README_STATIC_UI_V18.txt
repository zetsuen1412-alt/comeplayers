ComePlayers Homepage V18 - Static UI

Perubahan:
- Semua animasi berulang pada homepage dihapus.
- Tidak ada lagi gerakan cursor, breathing Alexia, portal pulse, scanline, atau ambience.
- Hanya ada efek hover/click sederhana pada tombol.
- Tombol Marketplace, Help Center, dan tombol lain dibuat satu baris agar tidak pecah.
- Route /marketplace dan /messages tidak diubah.

Cara pasang:
1. Hentikan server dengan Ctrl+C.
2. Extract isi ZIP langsung ke C:\Comeplayers-new\website
3. Pilih Replace/Timpa semua file.
4. Jalankan INSTALL_HOME_STATIC_UI_V18.bat
5. Jalankan npm run dev
6. Buka http://localhost:3000 lalu Ctrl+F5
