ComePlayers Dual World Portal Sound V13

Fitur:
- Tampilan sama dengan mockup Dual World Portal yang dipilih.
- Area Chat, Marketplace, How It Works, About Us, Help Center, Contact, Windows, dan Android dapat diklik.
- Tombol suara Sound On/Off dengan ambience serta efek hover/click sintetis.
- Tekan tombol M untuk mengaktifkan atau mematikan suara.
- Route /marketplace tidak diubah.

Cara pasang:
1. Hentikan server dengan Ctrl+C.
2. Extract seluruh isi ZIP langsung ke C:\Comeplayers-new\website
3. Pilih Replace / Timpa semua file.
4. Jalankan INSTALL_DUAL_WORLD_PORTAL_SOUND_V13.bat
5. Jalankan npm run dev
6. Buka http://localhost:3000 dan tekan Ctrl+F5

Opsional di .env.local:
NEXT_PUBLIC_COMEPLAYERS_PC_URL=https://alamat-download-pc
NEXT_PUBLIC_COMEPLAYERS_ANDROID_URL=https://alamat-download-android
NEXT_PUBLIC_SUPPORT_EMAIL=support@comeplayers.com
