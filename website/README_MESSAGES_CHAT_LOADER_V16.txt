ComePlayers Messages Chat Loader V16

Desain:
- Loading screen biru dengan ikon chat digital.
- Shimmer pada progress bar.
- Pulse pada ikon dan status Connected.
- Scanline dan sapuan cahaya lembut.
- Tidak memakai progress persentase palsu.

Cara pasang:
1. Hentikan npm run dev dengan Ctrl+C.
2. Extract seluruh isi ZIP langsung ke C:\Comeplayers-new\website
3. Pilih Replace / Timpa semua file.
4. Jalankan INSTALL_MESSAGES_CHAT_LOADER_V16.bat
5. Jalankan npm run dev.
6. Buka http://localhost:3000/messages lalu tekan Ctrl+F5.

Installer mendukung:
- loading lama berupa teks "Loading ComePlayers servers..."
- Messages Loading Operator V15

Backup page.tsx dibuat otomatis sebelum patch.
