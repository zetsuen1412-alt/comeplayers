COMEPLAYERS CINEMATIC LIVING ALEXIA V20

Fitur:
- Full-screen game lobby berbentuk video asli 60 FPS.
- Loop 6 detik yang mulus.
- Rambut Alexia bergerak halus.
- Badan bernapas ringan.
- Kepala bergerak sangat kecil.
- Alexia berkedip beberapa kali dan tersenyum lembut.
- Portal biru dan emas berdenyut halus.
- Tombol tetap berupa area HTML yang presisi dan responsif.
- Suara hover/click opsional melalui tombol Sound Off/On.
- Route /messages dan /marketplace tidak diubah.

Cara memasang:
1. Hentikan server dengan Ctrl+C.
2. Extract ZIP langsung ke C:\Comeplayers-new\website.
3. Pilih Replace / Timpa semua file.
4. Jalankan INSTALL_HOME_CINEMATIC_V20.bat.
5. Jalankan npm run dev.
6. Buka http://localhost:3000 dan tekan Ctrl+F5.

Link download opsional di .env.local:
NEXT_PUBLIC_COMEPLAYERS_PC_URL=https://alamat-download-windows
NEXT_PUBLIC_COMEPLAYERS_ANDROID_URL=https://alamat-download-android
NEXT_PUBLIC_SUPPORT_EMAIL=support@comeplayers.com
