# ComePlayers Marble V21

Pembaruan game papan ComePlayers dengan tampilan yang terinspirasi struktur gameplay Modoo Marble: papan berbentuk berlian, empat panel pemain, dadu di tengah, pembelian kota, gedung/landmark, kartu kejutan, biaya sewa, dan hasil pertandingan.

## Pemasangan

1. Ekstrak ZIP ke folder proyek utama yang berisi folder `Comeplayers-new`.
2. Izinkan Windows mengganti/menambahkan file.
3. Masuk ke `Comeplayers-new/website`.
4. Jalankan `npm run dev`.
5. Buka `http://localhost:3000/games/monopoly`.

## Fitur

- 4 pemain: Alexia + 3 bot.
- 32 petak papan.
- 12 putaran per pertandingan.
- Beli kota dan upgrade sampai level 4.
- Sistem sewa berdasarkan level properti.
- Kartu kejutan, pajak, bonus, pulau, festival, dan tur dunia.
- Fullscreen, suara toggle, log aktivitas, responsive desktop/mobile.
- Semua aset dan desain menggunakan identitas ComePlayers; tidak memakai aset Modoo Marble.
