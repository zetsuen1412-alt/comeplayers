COMEPLAYERS GAME LOBBY V6 - PIXIJS

FITUR:
- Layar PRESS ANY KEY seperti menu game.
- Animasi intro kamera, partikel, glow, parallax, dan idle breathing.
- Mouse, keyboard A/D + Enter, gamepad, dan touch.
- Sound ambience + UI tone buatan browser, dapat dimute.
- Tombol fullscreen desktop.
- Hover Chat/Marketplace mengubah pose Alexia dan menyalakan panel.
- Transisi scene sebelum membuka halaman.

INSTALL:
1. Hentikan npm run dev dengan Ctrl+C.
2. Ekstrak isi ZIP langsung ke folder website yang berisi package.json.
3. Klik INSTALL_GAME_LOBBY_V6.bat.
4. Jalankan npm run dev.
5. Buka http://localhost:3000 dan tekan Ctrl+F5.
