COMEPLAYERS GAME LOBBY V7 - REPLACE ZIP

1. Hentikan npm run dev dengan Ctrl+C.
2. Extract seluruh isi ZIP langsung ke folder website yang memiliki package.json.
3. Pilih Replace/Timpa semua file.
4. Jalankan INSTALL_GAME_LOBBY_V7.bat.
5. Jalankan npm run dev.
6. Buka http://localhost:3000 lalu Ctrl+F5.

Catatan:
- Header/footer otomatis disembunyikan hanya pada homepage.
- Chat membuka /messages.
- Marketplace membuka /marketplace.
- URL Download PC dan Android belum diketahui, jadi tombol menampilkan pemberitahuan.
  Masukkan URL pada fungsi pendingDownload di app/HomeClient.tsx.
