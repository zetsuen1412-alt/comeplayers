# ComePlayers Strike v0.4 — Black Core Update

## Installation

1. Back up `.env.local` and any local changes.
2. Extract the update patch into the directory that contains `Comeplayers-new`.
3. Allow existing files to be replaced.
4. From `Comeplayers-new/website`, run:

```bash
npm install
npm run dev
```

Open:

- `/play/comeplayers-strike` for the game.
- `/games/comeplayers-strike` for the landing page.

## Major changes

- Zombie Adventure expanded to seven chapters.
- Checkpoint revival and emergency supply cache.
- Dual-generator objective and final extraction sequence.
- New Crawler and Screamer infected.
- Three-phase Outbreak Colossus boss with summoned reinforcements.
- Explosive barrels with chain reactions.
- Health, armor, ammunition, and Overdrive pickups.
- Toxic waste hazards, catwalks, fences, and generator props.
- Combo, Overdrive, revive, and boss-phase HUD indicators.
