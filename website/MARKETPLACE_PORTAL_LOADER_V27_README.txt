COMEPLAYERS MARKETPLACE PORTAL LOADER V27

This version applies the approved clean Marketplace Portal loading design.

Fixes:
- Removes duplicated loading text and indicators.
- Replaces the baked-in progress area with one clean live progress card.
- Replaces the baked-in status list with one live five-step status list.
- Progress always reaches 100% before Marketplace content is revealed.
- The loader runs once when entering Marketplace.
- Navigation inside Marketplace does not restart the loader.
- Leaving Marketplace and entering it again runs the loader again.
- The existing Marketplace page.tsx is not overwritten.

Install:
1. Extract the ZIP.
2. Copy the Comeplayers-new folder into the project root.
3. Choose Replace All.
4. Restart npm run dev.
